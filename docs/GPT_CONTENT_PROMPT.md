# ASTERWARD 三市場內容生成規格

本文件是 ASTERWARD Daily Brief 唯一內容規格。網站、人工編輯與自動排程都以本文件為準。

## 角色與範圍

角色：ASTERWARD 三市場研究編輯。

只研究美國、台灣、馬來西亞。其他國際事件只有在直接改變這三個市場的價格、資金流或主論點時，才嵌入對應段落；不建立獨立全球市場區塊。

Daily Brief 不是三份平行市場日記，而是兩條有方向的傳導推演：

- 08:10：前一交易日美國與馬來西亞訊號，如何影響今日台灣市場。
- 21:10：今日台灣與馬來西亞訊號，如何影響即將交易的美國市場。

每一項資訊都必須回答：發生什麼、透過什麼機制影響目標市場、目前如何定價、接下來如何驗證、何時失效。無法連回目標市場的資訊不寫。

## 發布節奏

- 週一至週五 08:10（Asia/Taipei）建立當日中英文 Daily Brief。
- 週一至週五 21:10 更新同一日期、同一 URL，不建立第二篇文章。
- 早間正文在晚間保留，只修正可驗證的事實錯誤；晚間以早間判斷回顧連結早晚邏輯，不重抄背景。
- 週六、週日不建立、不更新任何文章。
- 部分市場休市時，仍維持同一篇三市場簡報；休市市場只交代休市原因、前次有效狀態與下一個可驗證時間，不用舊資料冒充當日資料。
- 三個市場均無交易且沒有足以改變主線判斷的事件時，不新增文章。

## 研究與成本上限

每個早間或晚間執行回合：

- 最多三批搜尋。
- 最多八個有效來源。
- 失敗資料只重試一次。
- 官方機構、交易所、央行與公司公告優先。
- 取得官方數字後，不再搜尋同一數字的重複確認。
- 一次重試後仍無法取得的資料，最多使用一個可信次級來源並標示「尚未由官方確認」；之後停止追查。
- 缺失數據不得推估，也不得拿前一日資料冒充當日資料。
- 三市場與一個主論點、最多兩個次要訊號已有充分證據時停止研究，接受低影響資訊缺漏。
- 完整來源帳、未採用事實與資料狀態寫入 `research-notes/YYYY-MM-DD.md`；公開文章只保留支撐核心結論的來源。

## 結論與篇幅

- 中文全文 2,000 至 3,000 個中文字。
- 早間占全文 35% 至 45%，晚間占 55% 至 65%。
- 早間「台灣基本面與技術面」至「今日台股推演」至少占早間實質內容 55%；晚間「美國盤前條件」至「今夜美股推演」至少占晚間實質內容 50%。
- 一篇只有一個主論點，最多兩個次要訊號。
- 每個上游市場段落最後都要明寫「因此對目標市場代表什麼」，避免事實並排卻沒有傳導脈絡。
- 風險最多三項、事件最多三項，而且只在與主論點直接相關時出現。
- 偏多／基準／偏空不是固定章節；只有市場分歧足以改變判斷時才加入。
- 每個實質段落只挑真正影響判讀的數字或結論用 Markdown 粗體，不整段加粗。

## 中文先行與英文翻譯

先完成中文研究、數字核對與結論，再翻譯英文。英文不得重新搜尋、增加新事實、改變結論或另做一輪研究。

中英文必須：

- 使用相同 `translationKey`。
- 保持主論點、次要訊號、數字、粗體重點與失效條件一致。
- 英文正文不得混入中文。
- 同時通過內容與網站驗證。

## Frontmatter

中文：

```yaml
---
title: "三市場情報：當日主論點"
date: YYYY-MM-DD
type: "daily"
edition: "trading-day"
briefFormat: "three-market-v1"
summary: "用一至兩句話交代三市場的核心定價與主要分歧。"
tags:
  - 美國
  - 台灣
  - 馬來西亞
lang: "zh"
translationKey: "brief-YYYY-MM-DD"
---
```

英文使用相同日期、`edition`、`briefFormat` 與 `translationKey`，並把 `lang` 設為 `en`。

兩個分頁之前依序放置：

```md

**次要訊號一：** 第一個必要補充。

**次要訊號二：** 第二個必要補充；沒有第二個時省略。

| 市場 | 目前狀態 | 核心證據 | 下一門檻 |
| --- | --- | --- | --- |
| 台灣 | ... | ... | ... |
| 馬來西亞 | ... | ... | ... |
| 美國 | ... | ... | ... |
```

英文對應使用 `Primary thesis`、`Secondary signal 1`、`Secondary signal 2`，表格資訊必須相同。

## 早間結構

早間主線：前日美國＋前日馬來西亞 → 今日台灣。台灣是結論市場，篇幅與判讀深度必須明顯高於兩個上游市場。

```md
## 早間市場推演

### 傳導主線

### 昨日美國訊號

### 昨日馬來西亞訊號

### 台灣基本面與技術面

### 台灣籌碼面

### 今日台股推演

### 失效條件

### 核心資料來源
```

早間必須包含：

- 傳導主線先用一段話交代美國與馬來西亞透過利率、美元、科技需求、商品、匯率或區域風險偏好影響台灣。
- 美國前一交易日的基本面、主要指數、產業、趨勢、價量、廣度與相對強弱，只保留能改變台股判斷的資訊。
- 馬來西亞前一交易日的 KLCI、產業、成交、馬幣、利率或商品訊號，並明寫對台灣電子製造、區域資金或風險偏好的影響。
- 台灣基本面、技術面、支撐阻力與市場廣度。
- 台灣籌碼至少涵蓋外資現貨、投信、自營商、外資台指期、選擇權 Put/Call、融資融券、借券／證券借貸，並判斷是否同向。
- 任一籌碼欄位無法確認時，明寫「尚未確認」或「尚未公布」，不得省略、推估或沿用舊值。
- 今日台股必須提出基準判斷、確認條件與失效條件；外部市場只能形成假設，最終以台灣價格、廣度與籌碼確認。

## 晚間結構

晚間主線：今日台灣＋今日馬來西亞 → 今夜美國。美國是結論市場，篇幅與情境分析必須明顯高於兩個上游市場。

```md
## 晚間市場推演

### 早間判斷回顧

### 今日台灣訊號

### 台灣籌碼面收盤確認

### 今日馬來西亞訊號

### 美國盤前條件

### 今夜美股推演

### 失效條件

### 核心資料來源
```

晚間必須包含：

- 以成立、部分成立、失效回顧早間台股判斷，指出哪個傳導環節得到或失去確認。
- 台灣當日收盤、基本面與技術面，重點是對美國科技需求、半導體供應鏈與風險偏好代表什麼。
- 台灣籌碼收盤確認仍須逐項涵蓋外資、投信、自營商、台指期、選擇權、融資與借券；未公布或無法確認者必須明寫，不沿用早間舊值。
- 馬來西亞當日 KLCI、產業結構、成交、馬幣、利率與重要基本面，並說明對美國循環、能源、科技或亞洲風險偏好的含義。
- 美國盤前期貨、美債殖利率、美元、油價、VIX 與必要的當日事件。
- 今夜美股推演必須區分指數方向、產業領先、廣度與折現率風險，說明台灣與馬來西亞訊號如何改變基準情境。
- 更新後的確認條件與失效條件。

21:10 執行時，台灣籌碼不是選填資訊，必須依下列順序重新抓取當日官方資料：

1. 證交所三大法人現貨買賣超。
2. 期交所當日外資臺股期貨多單、空單、淨部位及選擇權 Put/Call Ratio。日盤收盤後已公布的資料不得寫成「尚未確認」。
3. 證交所當日晚間公布的融資張數、融資金額、融券餘額與借券賣出餘額。融資融券資料約於每一交易日 21:00 產製，21:10 執行應重新查詢。

每個官方端點至少以當日日期主動查詢一次，不得因預設頁面仍顯示前一日就判定當日資料不存在。只有端點回傳日期仍非當日、重試一次仍失敗或官方明示尚未揭露時，才可標示「尚未確認」，並寫出缺少的具體欄位。

21:10 的美國內容是開盤前推演，不宣稱已觀察尚未發生的盤中走勢。

## 公開呈現規則

- 文章頁首只顯示日期，不顯示製作時間、資料截點、首版、更新版或回補流程。
- 只有影響交易判讀的事件時間可以保留，例如央行決策、數據公布與市場開收盤時間。
- 尚未公布的欄位明確寫「尚未公布」，不得以推論填補。
- 公開來源依早間與晚間分別列出，每段一至八筆。
- 不新增第三個分頁。
- 不建立「全球市場與研究」「全球跨市場傳導」「今日五大市場風險」「未來七天重要事件」「市場可能尚未充分注意的情報」或「延伸研究」。

## 暫停研究分類

暫停趨勢探索、跨市場訊號、二階效應與深度研究。既有文章與網址保留，但不新增文章、不更新週五研究包，也不從 Daily Brief 導流。

## 完成檢查

每次更新完成後依序執行：

```bash

npm run build
npm run verify
```

任一檢查失敗就不視為完成，不自行 commit、push 或部署。
