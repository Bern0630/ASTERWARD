# ASTERWARD 補充研究輸入

把個人觀點、外部資料或希望驗證的問題放在本資料夾。檔名必須使用報告日期與時段：

- `yyyy-mm-dd-morning-補充.md`
- `yyyy-mm-dd-evening-補充.md`

早報只讀取同日 morning 檔，晚報只讀取同日 evening 檔。內容會先查證，不會直接照抄到公開文章。

建議格式：

```md
# 補充研究資料

## 已確認事實
- 事件或數據：
- 發布日期：
- 原始來源：
- 連結：

## 我的觀點
- 我認為：
- 可能影響：

## 希望驗證
- 問題一：
- 問題二：
```

請盡量保留原始連結、數字單位與發布日期；沒有來源的內容會視為研究假設。
