# ASTERWARD OLD_VERSION

This directory preserves the complete public-content system that existed before the editorial reset on 2026-09-30.

Nothing in this directory is loaded by Astro Content Collections or published by the current site. Paths are intentionally preserved so every archived file can be traced back to its former location.

Archive contents include:

- all Chinese and English articles from the five content collections;
- dated research inputs and unpublished research ledgers;
- previous content templates and editorial instructions;
- the previous homepage, About pages, content indexes, site copy, and verification scripts;
- the previous project README.

Do not edit archived material in place. Future research belongs in the active project structure outside `OLD_VERSION`.
