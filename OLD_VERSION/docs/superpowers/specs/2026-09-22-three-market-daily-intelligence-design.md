# ASTERWARD 三市場每日情報重整設計

狀態：待使用者書面規格審閱  
決策日期：2026-09-22  
預定切換：2026-09-23 起套用至自動排程

## 1. 目標

ASTERWARD 的每日產品只服務三個市場：**美國、台灣、馬來西亞**。每天用同一篇中英文文章完成早晚兩次判讀，讓讀者快速知道：

1. 已確認的市場事實是什麼。
2. 市場如何定價，主論點與最多兩個次要訊號是什麼。
3. 接下來最可能的方向，以及什麼條件會讓判斷失效。

本次重整同時降低研究與生成成本。每日文章不再承擔全球新聞彙整、教學、週度研究或所有可得數據的保存功能。

## 2. 非目標

- 不新增第四個主要市場。
- 不建立獨立「全球市場與研究」日報分頁。
- 不在每日文章固定產出跨市場傳導、五大風險、七日事件、市場遺漏或延伸研究。
- 不繼續排程趨勢探索、跨市場訊號、二階效應、深度研究或週五研究包。
- 不刪除既有研究文章、集合或可直接開啟的舊網址。
- 不建立第二份專案，不部署，不啟動開發或預覽伺服器。

## 3. 發布節奏

### 08:10 早間市場推演

建立當日同一篇 Daily Brief 的中英文版本，內容約占中文全文 40%。

- **美國前一交易日：**基本面、指數與產業表現；技術面只看趨勢、價量、廣度、支撐阻力與相對強弱。
- **台灣前一交易日：**基本面、技術面與完整籌碼面。
- **台灣籌碼：**外資現貨、台指期、選擇權、投信、自營商、融資融券、借券／證券借貸；判斷彼此是否同向。
- **推演：**提出當日台股走勢與當日美股盤前狀態的基準判斷。
- **失效條件：**只列能明確推翻主論點的價格、利率、資金流或事件條件。

### 21:10 晚間市場推演

更新同一日期、同一 URL，不另建文章；內容約占中文全文 60%。早間正文保留，僅修正可驗證的事實錯誤。

- **盤前判斷回顧：**以成立、部分成立、失效回顧早間主論點與訊號，不重述背景。
- **台灣：**當日收盤、基本面、技術面與完整籌碼面。
- **馬來西亞：**當日收盤、產業結構、馬幣、利率及重要基本面；沒有重大新聞時仍需說明價格與基本面狀態。
- **美國：**盤前期貨、美債殖利率、美元與油價，推演即將開始的美股交易時段。
- **失效條件：**更新當晚真正需要監控的推翻條件。

21:10 的美國內容明確定位為**開盤前推演**，不宣稱已觀察尚未發生的盤中走勢。

### 休市與週末

- 週六、週日不新增、不更新文章。
- 平日若部分市場休市，仍維持同一篇三市場日報；休市市場只交代休市原因、前次有效狀態與下一個可驗證時間，不拿舊資料冒充當日資料。
- 三個市場均無交易且沒有足以改變三市場判斷的事件時，不新增文章。

## 4. 文章契約

### 篇幅與結論

- 中文全文控制在 **2,000 至 3,000 個中文字**，早間約 40%、晚間約 60%。
- 每日只有 **一個主論點**，最多 **兩個次要訊號**；全篇最多三個核心結論。
- 風險最多三項、事件最多三項，而且只在與主論點直接相關時出現。
- 偏多／基準／偏空情境不是固定章節；只有市場分歧足以改變交易判斷時才加入。
- 全球事件只有在直接影響美國、台灣或馬來西亞時，才嵌入相應市場段落。

### 頁首摘要區

分頁前保留精簡的共用摘要：

1. 日期、標題、摘要、標籤與研究標籤。
2. 「今日主論點」一段，不重複正文。
3. 一張三市場總覽表，欄位固定為「市場／目前狀態／核心證據／下一門檻」。晚間可更新這張表，但不得藉此改寫早間正文。

### 新版兩分頁

新版 `briefFormat: "three-market-v1"` 使用兩個 H2 作為分頁邊界：

```md
## 早間市場推演
### 美國前一交易日
### 台灣前一交易日
### 今日台股推演
### 今日美股盤前推演
### 失效條件
### 核心資料來源

## 晚間市場推演
### 盤前判斷回顧
### 台灣市場
### 馬來西亞市場
### 美國盤前與今夜推演
### 失效條件
### 核心資料來源
```

不適用的小節可以省略，但兩個 H2 與三個晚間市場入口不得缺少。英文使用語意一一對應的固定標題，不自行增加研究。

### 中英文工作流

先完成中文研究與判讀，再製作英文忠實翻譯。英文版不得另開搜尋流程、增加新事實或改變結論；兩版的 `translationKey`、主論點、數字、粗體重點與失效條件需對應。

## 5. 研究與成本控制

每個 08:10 或 21:10 執行回合均遵守：

- 最多三批搜尋，最多八個有效來源。
- 官方機構、交易所、央行與公司公告優先；取得官方數字後不再搜尋同一數字的重複確認。
- 失敗資料只重試一次；仍無法取得時，最多使用一個可信次級來源並標示「尚未由官方確認」，之後停止追查。
- 不以推論補齊缺失數據，也不使用前一日數據冒充當日數據。
- 三市場與一主論點、兩個次要訊號已有足夠證據時立即停止研究，接受低影響資訊缺漏。
- 公開文章只列支撐核心結論的來源；完整來源帳、未採用事實與資料狀態記錄於不公開的 `research-notes/YYYY-MM-DD.md`，按早間與晚間分區。

研究筆記不加入 Astro Content Collections，不產生公開路由。

## 6. 網站資訊架構

- 中文主導覽只保留「每日簡報」「關於」與語言切換；英文為 `Briefs`、`About`。
- 首頁移除趨勢探索、跨市場訊號、二階效應與深度研究區塊，首頁文案改為三市場每日情報定位。
- 既有四類研究頁、文章與 direct URL 全部保留，不從主導覽或首頁曝光。
- 新版日報顯示兩個分頁；舊文章維持既有三分頁與內容，不做批次改寫。
- 內容 schema 新增有預設值的 `briefFormat`：舊文預設 `legacy-three-panel`，新版使用 `three-market-v1`。版面依欄位決定兩分頁或舊三分頁，不以偶然出現的標題猜測格式。
- 手機版沿用精簡分頁與可收合章節導覽；側邊／章節連結切換到正確分頁後，標題需停在 sticky header 下方。

## 9. 驗收標準

- 讀者只看到美國、台灣、馬來西亞的每日主線。
- 08:10 與 21:10 更新同一篇文章，沒有內容覆蓋或重複文章。
- 新文只有早間、晚間兩分頁，晚間三市場可由章節導覽直接進入。
- 每篇只有一個主論點與最多兩個次要訊號，沒有固定全球填充章節。
- 研究流程受三批搜尋、八來源與一次重試上限約束。
- 英文是中文忠實翻譯，不重做研究。
- 舊研究與舊日報網址仍可開啟，主導覽與首頁不再曝光 pending 研究。
- 現有自動化被更新並於驗證後啟用，沒有重複 task。
